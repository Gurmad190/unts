# University of Northeastern Somalia (UNS) Website

This is the official website for the University of Northeastern Somalia (UNS), based in Garowe, Puntland, Somalia.

## Project Status

- **Project Type**: React + TypeScript Web Application
- **Framework**: React 18
- **Styling**: Tailwind CSS (Custom UNS Theme)
- **Icons**: Lucide React
- **Routing**: React Router DOM v6
- **Build Tool**: Vite 7

## Brand Identity

- **Logo**: `/uns-logo.jpg` (UNS shield with motto "Great Minds Build Nations")
- **Primary Color**: Deep Navy Blue (#002147)
- **Secondary/Accent**: Gold/Yellow (#FFBF00)
- **Highlights**: Crimson Red (#DC143C)
- **Fonts**: Inter (body), Playfair Display (headings)

## Website Structure (10 Main Pages)

1. **Home** (`/`) — Hero, overview, featured programs, flexible learning, why UNS, news
2. **About** (`/about`) — Commitment, vision, mission, core values, at-a-glance stats
3. **Academics** (`/academics`) — 17 programs across 4 academic areas
4. **Academics Detail** (`/academics/:slug`) — Individual program pages with overview, key areas, careers
5. **Admissions** (`/admissions`) — Why UNS, available programs, how to apply, learning options
6. **Research** (`/research`) — Research areas, activities, international collaboration, opportunities
7. **Students** (`/students`) — Student life, support services, online learning, training
8. **International** (`/international`) — Global engagement, scholarships, research collaboration
9. **Career Development** (`/career`) — Career services, readiness areas, graduate opportunities
10. **News & Events** (`/news`) — University news, announcements, events
11. **Contact** (`/contact`) — Contact info, form, office hours, map location
